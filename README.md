# Twitter Video Card

WordPress plugin that adds X/Twitter **Player Card** and Open Graph video tags to posts and pages.

- YouTube (incl. Shorts), Vimeo and direct `.mp4` URLs
- Built-in HTML player page for MP4 files (required by Twitter's player card)
- YouTube thumbnail fallback when no featured image is set
- Settings page (Settings → Twitter Video Card): site handle, player size, post types

## Usage
1. Upload the folder to `wp-content/plugins/` and activate.
2. Set your handle under Settings → Twitter Video Card.
3. Paste a video URL into the "Twitter Video Card" box while editing a post.

Note: Twitter requires HTTPS for player and video URLs.
